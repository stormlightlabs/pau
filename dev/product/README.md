# Product specification

These documents define what Pau does and what it leaves out. Read all of them
before changing a product requirement, and update the owning document in the
same change when a product decision changes.

- [Overview](overview.md): purpose, core concepts and adapter capabilities.
- [Required workflows](workflows.md): workspaces, agents, editor, terminal,
  resources, permissions, diagnostics, and the desktop and web apps.
- [Safety and persistence](safety-and-persistence.md): security boundaries,
  sandbox requirements and stored state.
- [First-release scope](first-release-scope.md): shipped themes and explicit
  non-goals.

The Technical plan, which sets architecture and implementation policy, lives in
Linear on the team PAU. [`dev/design`](../design/README.md) records interface
decisions.
