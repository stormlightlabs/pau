# First-release scope

## Themes

The first release ships Eldritch, Nord, Iceberg, Catppuccin Mocha and Vitesse
Dark. A theme covers the application shell, semantic states, syntax
highlighting, terminal ANSI colors and CodeMirror. Pau does not replace the
theme or configuration of an external or terminal editor.

## Non-goals

The first release does not include:

- cloud sandboxes or hosted execution
- remote machine control before a separate transport and security design is
  complete
- multiplayer editing
- autonomous agent councils
- a visual workflow language
- a reimplementation of Git, a full editor, Pi or an LSP client in the frontend
- deep browser embedding of Neovim, Vim, Helix or another external editor
- an event model that reduces every agent to a false lowest common denominator
